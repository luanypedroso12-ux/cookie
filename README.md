# cookie
Um repositório criado para a melhor explicação sobre o que são Cookies.

## Site de Ferramentas de Busca e Mapas

Este projeto inclui um site simples em HTML, CSS e JavaScript que usa cookies para salvar as preferências do usuário.

Arquivos:
- `index.html`
- `styles.css`
- `script.js`

### Funcionalidades
- pesquisa usando Google, Bing, DuckDuckGo ou Ecosia
- mapas usando Google Maps, OpenStreetMap ou Bing Maps
- salva motor de busca, serviço de mapas e histórico usando cookies

### Uso
Abra `index.html` no navegador para testar o site.
